# E-commerce Store SQL Data Analysis

## 📌 Project Overview
This project focuses on analyzing an E-commerce Store database using MySQL. It demonstrates SQL skills such as database management, data retrieval, filtering, joins, aggregations, and data analysis to extract meaningful insights from store data.

## 🎯 Project Objectives
- Design and manage an E-commerce database.
- Store and organize data using SQL tables.
- Retrieve useful information using SQL queries.
- Analyze sales and other business-related data.
- Practice SQL skills for real-world data analysis.

## 🛠️ Tools & Technologies
- **Database:** MySQL
- **Tool:** MySQL Workbench
- **Language:** SQL

## 📂 Project Files
- `E-commerce Store project.sql` — SQL script containing database setup and project queries.

## 🔍 Key SQL Concepts
- Database and table creation
- Data insertion and retrieval
- `SELECT`, `WHERE`, and `ORDER BY`
- Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`
- `GROUP BY` and `HAVING`
- Joins and subqueries, where applicable

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open MySQL Workbench.
3. Open the `E-commerce Store project.sql` file.
4. Select or create the required database.
5. Execute the SQL statements in the correct order.
6. Review the query results to understand the analysis.

## 📈 Learning Outcomes
- Improved practical understanding of MySQL.
- Experience writing SQL queries for data analysis.
- Better understanding of database organization and business data.
